CRM Grandes Soluções — versão funcional local

COMO TESTAR NO CELULAR ANDROID
1. Baixe crm.html.
2. Abra o arquivo e escolha Chrome.
3. Autorize o microfone quando o navegador pedir.
4. Teste "+ Novo cliente" e depois "🎤 Voz".
5. Os dados ficam salvos neste aparelho/navegador nesta versão de teste.

IMPORTANTE
Esta versão já é funcional para teste, mas ainda é LOCAL: ela não compartilha dados entre celulares. A próxima etapa é publicar o sistema na internet com banco de dados e logins individuais para todos os vendedores.

Se o Android não abrir o HTML diretamente, extraia o ZIP e abra crm.html pelo Chrome/gerenciador de arquivos que ofereça "Abrir com navegador".
